# Vinayak LoanVault

A modern Gold Loan Management & Dashboard application built with React, Vite, and Lucide Icons.

## Features
- **Dashboard & Analytics**: Real-time stats, interest overview, and loan breakdown.
- **Customer 360 & Management**: Detailed customer profiles, KYC, active loans, and payment history.
- **New Loan Creation**: Streamlined loan origination workflow with dynamic interest & ornament calculations.
- **EMI & Payment Tracker**: Track dues, mark payments, and generate PDF receipts.
- **Reports & Export**: Export customer and financial reports.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
